OpenCode Temaları — UI Önizleme

Renkler fetched/*.json dosyalarındaki dark paletlerinden birebir alınır. Her kart, OpenCode masaüstü arayüzünün mock-up'ıdır: aynı içerik, tema renkleriyle. Tema bir rolü tanımlamamışsa uygulama kendi fallback zincirini uygular (ör. diffAdd boşsa soldurulmuş success). Kart altındaki efsanede "—" = tema o rengi tanımlamamış; swatch renk, mock'ta fiilen kullanılan rengi gösterir.

Mockup bölgeleri → renk rolleri:
• Pencereler arka fonu & içerik metni → neutral (bg) + ink  •  Kenar çubuğu soluk öğeler → text-weak  •  Aktif oturum / odak / baloncuk → interactive
• Avatar & brand → primary  •  Başlık "Deployment Rehberi", link, listeler → markdown-*  •  Kod bloğu → syntax-* (keyword, dizgi, ilkel, tip, özellik, sabit, değişken, operatör, noktalama, yorum)
• Diff paneli → diffAdd / diffDelete  •  Alt durum çubuğu → success / warning / error / info  •  Başlık çubuğu "aktif" rozeti → info-ye yakın (interactive)
